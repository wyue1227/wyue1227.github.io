# 五十音练习 · 日语入门

一个给日语初学者用的五十音练习网站。手机优先、中文界面、免费托管在 GitHub Pages，
**练习记录只保存在本机浏览器（IndexedDB）里，不需要注册、不需要登录、不上传服务器。**

## 目录结构

```
.
├── site/                     # 网站本体 —— GitHub Pages 只发布这个目录
│   ├── index.html            # 单页应用入口
│   ├── css/style.css         # 全部样式（无外部字体 / 无 CDN）
│   ├── js/
│   │   ├── data.js           # 五十音清音数据（平假名 46 / 片假名 46，空位不编造）
│   │   ├── db.js             # IndexedDB 数据层 + 导入导出校验
│   │   └── app.js            # 界面与测验逻辑
│   ├── sw.js                 # Service Worker（离线缓存，不触碰 IndexedDB）
│   ├── manifest.webmanifest  # PWA 清单
│   ├── icons/                # 站点图标
│   └── .nojekyll
├── .github/workflows/pages.yml  # GitHub Pages 部署（官方方式，内置 GITHUB_TOKEN）
├── docs/                     # 本地开发与验收说明
└── .gitignore
```

## 本地预览

纯静态站，不需要安装依赖、不需要构建。任选一种：

```bash
# 方式一：Python 自带服务器（推荐，Service Worker 需要 http 协议）
cd site && python3 -m http.server 8137
# 然后浏览器打开 http://127.0.0.1:8137/

# 方式二：Node
cd site && npx --yes serve -l 8137 .
```

> 直接双击 `index.html`（`file://` 协议）也能练习，但 Service Worker 与 PWA 安装不可用。

手机上预览：让手机和电脑在同一局域网，把服务改成 `--bind 0.0.0.0`，手机访问 `http://电脑IP:8137/`。

## 已实现的功能

- **五十音表**：平假名 / 片假名切换，清音各 46 音，空位保持空白；可按行筛选；每个格子显示练习状态。
- **分行学习**：あ行 / か行 / … / ん 一键开练。
- **随机测验**：看假名选罗马音、看罗马音选假名、混合出题；每轮 10 题（可选 20 题）；
  选项不重复且只有一个正确答案；答完先显示正确答案，由用户点「下一题」，不会自动跳走。
- **错题复习**：最近一次作答错误的假名进入错题本，复习中答对即移出；另有「易错排行」。
- **练习统计**：每个假名的练习次数与正确率、每日练习记录、连续练习天数。
- **明确区分状态**：`未练习` 显示为「—」而不是 0% 正确率；`待复习` 单独标记。
- **数据备份**：导出 JSON（含版本号）、导入前校验结构并预览、覆盖前确认、失败自动回滚。
- **离线可用**：首次加载后 Service Worker 缓存资源，断网可继续练习。

## 数据与隐私

- 数据存储：浏览器 IndexedDB，数据库名 `gojuon-db`。
- 不发送任何网络请求（除加载本站自身资源）。
- 换手机 / 换浏览器 / 清理网站数据后记录不会跟随，需要先在「我的 → 数据备份」导出，再在新设备导入。
- 无痕 / 隐私模式下数据在窗口关闭后消失，不适合保存练习记录。

## 发音说明

- 站点**没有内置真人录音**，也**没有调用任何在线语音接口**。
- 「我的 → 设置」里可开启**系统语音合成**（Web Speech API）作为可选辅助，
  界面中明确标注为「系统语音」，不称为真人发音；设备没有日语音色时会提示，不影响练习。
- 将来若引入日语音频，必须是授权明确的文件，随站点一起部署并注明来源。

## 部署

推送到 `main` 分支即触发 `.github/workflows/pages.yml`，把 `site/` 目录发布到 GitHub Pages。
首次使用需要在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

详见 [`docs/本地开发与部署说明.md`](docs/本地开发与部署说明.md)。

## 片假名专项入口

首页选择「片假名」，即可直接开始专项，或点「カ行」等按钮按行练习。
错题本选择「片假名」，只复习片假名错题。平、片假名练习记录分别保存。
