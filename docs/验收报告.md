## 二、完成的功能

### 五十音数据
- 清音平假名 46 音、片假名 46 音，一一对应，罗马音各 46 个互不重复。
- 空位共 5 处（や行 い段/え段、わ行 い段/う段/え段），渲染为**完全空白的虚线格**，不编造任何字符。

### 五十音表
- 平假名 / 片假名一键切换，五列（あ段〜お段）× 十行 + ん。
- 按行筛选（全部 / あ行 / か行 / … / ん）。
- 每格显示假名 + 小号罗马音；颜色区分「未练习 / 正确率 ≥80% / 正确率 <80% / 最近答错」，右上角有状态角标。
- 点击任意假名弹出详情：状态、练习次数、正确率、答对/答错、最近作答时间，可直接「练这一行」。

### 分行学习
- あ行〜ん 每行一个按钮，点击直接用该行假名开练。

### 随机测验
- 三种题型：看假名选罗马音 / 看罗马音选假名 / 混合出题。
- 每轮 10 题（可选 20 题）；选项 4 个、**互不重复**、**恰好一个正确答案**。
- 干扰项优先取同一行的假名，让练习更聚焦；当范围不足 4 个（如错题只有 2 个、や行只有 3 个）时自动从整张假名表补足，保证仍是 4 个不重复选项。
- **答完先显示正确答案，必须点「下一题」才继续，不会自动跳走**；答错的选项标红、正确答案标绿。
- 可选「优先出还没练习过的假名」（未练习权重 4、待复习权重 3）。
- 一轮结束有结果页：得分、正确率、用时、本轮错题清单，可「再练一轮 / 复习本轮错题 / 打开错题本」。

### 错题复习
- 错题本口径：**最近一次作答为错误**的假名；复习中答对即移出，再答错则继续保留。
- 另有「易错排行」（按累计答错次数排序）。
- 复习时的干扰项自动从整张假名表补充。

### 统计与状态口径
- 每个假名的练习次数、正确率；每日练习记录（14 天柱状图）；连续练习天数。
- **明确区分「未练习」和「答错」**：
  - 未练习 → 徽章「未练习」，正确率显示 `—`，**绝不显示 0%**；
  - 最近答错 → 徽章「待复习」；
  - 正确率 ≥80% → 「已掌握」；<80% → 「练习中」。
- 首页直接显示「继续练习」，无需登录、无任何表单。

### 本地保存（IndexedDB）
- 数据库 `gojuon-db` v1，三个仓库：`kanaStats`（按假名）、`daily`（按日期）、`settings`。
- 刷新、关闭再打开均保留；一轮结束自动累加当日轮次。

### 导出 / 导入
- 导出 JSON，含 `app` 标识、`version`（v1）、`exportedAt`、`counts` 与三部分数据；文件名带时间戳。
- 导入前**先校验结构**（JSON 可解析 → app 标识 → 版本不高于当前 → data 三数组存在 → 逐条字段类型与数值关系 → 日期格式），任一不通过则整体拒绝、**不写库**。
- 校验通过后弹预览（导出时间、版本、假名数、每日记录天数与日期范围、答题总数与正确率），**确认后才覆盖**。
- 覆盖在单个 IndexedDB 事务中完成；写入失败自动回滚为导入前的数据。
- 清空记录**二次确认**（第一次确认 → 第二次「再确认一次」），第二次取消则数据不变。

### 发音与离线
- **零外部资源**：不引用 Google Fonts、任何 CDN、任何在线语音接口。字体全部使用系统字体栈，并可选「黑体 / 明朝体」。
- **不伪造音频**：站点没有内置任何音频文件，界面明确写「本站发音音频：暂未提供」。
- 系统语音合成（Web Speech API）作为**可选**功能，界面标注为「系统语音」并注明「不是真人发音」；设备无日语音色时给出明确提示，**不阻塞练习**。
- Service Worker 预缓存 9 项必需资源；断网刷新可打开、可继续测验、可写入记录。缓存升级只删除旧的 `gojuon-shell-*` 缓存，**绝不触碰 IndexedDB**。

### 部署配置
- `.github/workflows/pages.yml` 已替换为官方 Pages 部署方式：`actions/configure-pages` → `actions/upload-pages-artifact`（`path: ./site`）→ `actions/deploy-pages`。

### 验证中发现并修复的两个真实 Bug

1. **弹层遮罩挡住整页点击（严重）**
   `.sheet-backdrop { display: flex }` 的优先级高于浏览器默认的 `[hidden] { display: none }`，导致隐藏的遮罩层仍然覆盖全屏、拦截所有点击，网站实际不可操作。
   修复：加全局 `[hidden] { display: none !important; }`。

2. **「我的」页横向溢出 69px（严重）**
   每日记录条形图的 14 个日期标签（`10/16`）撑宽了 flex 行；同时设置项「朗读」的长标签因 `flex: 0 0 auto` 无法收缩。页面被撑到 459px，移动端布局视口随之被放大，**底部导航被挤出可视区域、无法点击**。
   修复：`.day { flex: 1 1 0; min-width: 0 }` 且标签只显示「日」；长文案设置项改用堆叠式 `.setting` 布局。修复后五个视图在 390px 下均无溢出。
